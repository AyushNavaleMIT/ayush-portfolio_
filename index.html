Introduction

I'm an Information Technology student at MITAOE Pune with a strong pull toward Artificial Intelligence. I like turning an idea into something people can actually open, use and learn from, whether that's a campus platform, a network diagnostics tool or a health-tech concept.

How I solve problems

I start by understanding what is actually going wrong, break it into smaller pieces, and test each piece before moving on. Whether it's a connectivity fault or a confusing interface, the goal stays the same: find the root cause, then build the clearest fix.

What I explore

Machine learning, data analysis and visualization, network monitoring, and front-end development. I try new tools often, and I treat each project as a chance to learn something I didn't know before.

Philosophy

Keep learning, keep building, and ship things that matter. Good engineering is curiosity with discipline.
